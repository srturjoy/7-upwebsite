# Video Media Assets

This directory is designated for local and preview video assets (e.g. `.mp4`, `.webm`) utilized for client case studies, background ambient video, or reels showcases.

## Guidelines
- For optimal web performance, host large video files (>5MB) on dedicated streaming CDNs or YouTube/Vimeo embeds.
- For short background looping video clips, encode in both H.264 (`.mp4`) and VP9/AV1 (`.webm`) with the audio track stripped (`muted`).
- Always specify poster preview frames using optimized PNG/WebP images.
